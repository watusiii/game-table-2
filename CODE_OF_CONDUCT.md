# Code of Conduct

This is a place for making things together. To keep it that way:

- Be kind and assume good intent. Disagree with ideas, not people.
- No harassment, hate, or personal attacks.
- Do not share other people's private information.
- Keep feedback specific and useful.

The maintainer can remove comments, issues, and pull requests, and block people, that break these rules. To report a problem, use GitHub's report tools or open the Security tab for anything sensitive.
